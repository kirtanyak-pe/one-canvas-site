One Canvas

Design on your real code.

Open a React + TypeScript project and see every screen and component on one canvas. Select anything, change text, props, spacing and colours, and the edits go straight into the code. It all runs on your Mac; nothing is uploaded.

Download for Mac Version 0.1.0 · 22 MB · Apple Silicon · test build

Before you start

  • A Mac with Apple Silicon (M1 or newer), macOS 12 or newer.
  • Node.js 20 or newer, free from nodejs.org. If it's missing, One Canvas tells you and opens that page.
  • A React + TypeScript project folder (.tsx files). Flutter, React Native and Vue aren't supported yet.

Install

  1. Open the downloaded One-Canvas.dmg and drag One Canvas onto Applications.
  2. The first time, right-click One Canvas in Applications → Open → Open. It's a test build without an Apple developer signature, so macOS asks once.
macOS only offers "Move to Bin" or "Done"?

Click Done, then go to System Settings → Privacy & Security, scroll down and click Open Anyway next to One Canvas. Or run this once in Terminal:

xattr -dr com.apple.quarantine "/Applications/One Canvas.app"

Use

  1. Open One Canvas, choose Open project… and pick your project folder.
  2. Every screen or component appears on the canvas. Click to select, double-click to go inside a component or edit its text, ⌘-click to pick the deepest part.
  3. Changes are written into that folder's files. Review them in git as usual.
  4. To quit: Home → Quit One Canvas, or close all its windows.

Something went wrong?

Send the log to the person who shared this link: ~/Library/Logs/One Canvas.log
